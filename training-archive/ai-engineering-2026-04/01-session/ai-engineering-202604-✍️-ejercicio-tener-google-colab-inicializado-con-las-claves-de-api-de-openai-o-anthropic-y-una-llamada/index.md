## Tu primera llamada a un LLM vía API

### Objetivo

Conectar con la API de un LLM desde código Python y obtener una respuesta exitosa.

### Formato

Google Colab Notebook

**Repositorio del ejercicio**
👉[https://github.com/LIDR-academy/ai-engineering-pre-sessions](https://github.com/LIDR-academy/ai-engineering-pre-sessions)(Accede a la carpetasession_01y abre el notebook del ejercicio)

Este notebook incluye:

- 

Setup completo del entorno (instalación de librerías y configuración de API keys)

- 

Ejemplos funcionales para OpenAI y Anthropic

- 

Código base para los niveles 1, 2 y 3 del ejercicio

Puedes usarlo directamente en Google Colab como punto de partida para completar el ejercicio.

**Recomendación:**
Si es tu primera vez trabajando con APIs de LLMs, utiliza este notebook.
Si ya tienes experiencia, puedes intentar hacerlo desde cero.

### Proveedor

A tu elección:**OpenAI**o**Anthropic**. Usa la cuenta que configuraste en el primer ejercicio. El notebook incluye código para ambos proveedores.

### Niveles

**Nivel 1 (obligatorio):**Realiza una llamada básica a la API del proveedor que elijas. Envía un mensaje, recibe una respuesta e imprímela por pantalla.

**Nivel 2 (obligatorio):**Añade un system prompt que dé al modelo un rol concreto — por ejemplo, un experto en estimación de proyectos de software. Envía el mismo mensaje que en el nivel 1 y compara las diferencias en la respuesta.

**Nivel 3 (opcional):**Extrae los metadatos de la respuesta: tokens de entrada, tokens de salida, modelo utilizado. Calcula el coste estimado de la llamada usando las tarifas publicadas del proveedor.

### Entrega

No hay entrega formal. Debes llegar a la sesión en vivo con los niveles 1 y 2 funcionando. En la primera parte de la sesión resolveremos posibles dudas que hayas tenido durante el proceso.
