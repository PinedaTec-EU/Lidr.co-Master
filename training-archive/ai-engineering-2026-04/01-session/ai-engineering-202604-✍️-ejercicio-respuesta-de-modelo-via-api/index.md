# Tu primera llamada a un LLM vía API

## Objetivo

Realizar tu primera integración real con un LLM desde código Python:
enviar un mensaje, recibir una respuesta y entender cómo cambia el comportamiento del modelo.

Este ejercicio utiliza la API que configuraste en el ejercicio anterior.

## Formato

Google Colab Notebook

## Proveedor

A tu elección:**OpenAI**o**Anthropic**. Usa la cuenta que configuraste en el primer ejercicio. El notebook incluye código para ambos proveedores.

## Niveles

**Nivel 1 (obligatorio):**

- 

Realiza una llamada básica a la API

- 

Envía un mensaje simple

- 

Recibe una respuesta

- 

Imprímela por pantalla

👉Si ves una respuesta sin errores, el setup es correcto

**Nivel 2 (obligatorio):**

- 

Añade un**system prompt**que defina un rol (ej: experto en estimación de software)

- 

Envía el mismo mensaje que en el nivel 1

- 

Compara la respuesta

👉Observa:

- 

tono

- 

nivel de detalle

- 

estructura de la respuesta

**Nivel 3 (opcional):**

- 

Extrae los metadatos de la respuesta:

- 

tokens de entrada

- 

tokens de salida

- 

modelo utilizado

- 

Calcula el coste estimado de la llamada

Puedes usar la documentación oficial de precios:

- 

OpenAI:[https://platform.openai.com/pricing](https://platform.openai.com/pricing)

- 

Anthropic:[https://www.anthropic.com/pricing](https://www.anthropic.com/pricing)

## Entrega

Debes llegar a la sesión en vivo con:

- 

Nivel 1 funcionando

- 

Nivel 2 funcionando

En la sesión resolveremos dudas y avanzaremos sobre esta base.

### Problemas comunes

Si algo no funciona, revisa:

- 

¿Tienes crédito disponible en tu cuenta?

- 

¿La API key está bien configurada?

- 

¿Estás usando el modelo correcto?

- 

¿Has instalado correctamente la librería?
